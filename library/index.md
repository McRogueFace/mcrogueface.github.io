# Library

A gallery of runnable examples for McRogueFace: bite-sized **playground snippets**, full **engine demo screens**, and **games**. Source links are pinned to specific commits so they keep working as the code evolves.

<sub>Snippets pinned to site `ba92e42` ([McRogueFace/mcrogueface.github.io](https://github.com/McRogueFace/mcrogueface.github.io)); demos/games pinned to engine `0.2.8` ([jmccardle/McRogueFace](https://github.com/jmccardle/McRogueFace)). Generated by `tools/build_library.py`.</sub>

## Playground Snippets

282 focused, copy-paste examples covering the whole `mcrfpy` API. Each snippet fills the 1024x768 playground canvas.

> **Open in playground:** the [playground]({{ site.baseurl }}/playground/) accepts shared code via an LZString-compressed `#src=` URL fragment or a `#gist=` id, but there is **no by-URL loader** to open a repo snippet directly. Copy the source below and paste it into the editor, then press Run (Ctrl+Enter).
